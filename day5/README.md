# Day 5 - Git Branching
 
## Topics Learned
 
- Git branch
- Git switch
- Git checkout
- Git merge
- Git status
- Git log
- Git diff
- Feature branches
- Merge conflicts
- Pull request concept
 
## Important Commands
 
git branch
git branch -a
git switch <branch>
git switch -c <new-branch>
git status
git log --oneline
git diff
git merge <branch>
 
## DevOps Workflow
 
Developer creates feature branch
        ↓
Developer makes changes
        ↓
git add
        ↓
git commit
        ↓
Push branch to remote repository
        ↓
Create Pull Request
        ↓
Code review
        ↓
Merge
        ↓
CI/CD pipeline
